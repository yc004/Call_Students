# 微信直接扫码进入小程序配置

系统已兼容两种二维码入口：

- 未配置直达链接：用户需要先打开小程序，再使用小程序内的扫码按钮。
- 配置直达链接：用户可直接使用微信“扫一扫”，微信会打开小程序并进入教室连接或教师端登录流程。

> 微信目前不允许个人主体小程序发布“普通链接二维码打开小程序”规则（接口错误码 `85075`）。当前项目为个人主体时，下面的普通链接方式只能用于开发兼容，不能上线启用。个人主体需要部署安全的服务端，通过 `getUnlimitedQRCode` 等服务端接口生成小程序码；AppSecret 只能保存在该服务端。

## 微信公众平台配置

1. 准备一个可验证归属的 HTTPS 域名和固定路径，例如 `https://example.com/classroom`。
2. 在微信公众平台为当前小程序配置“扫普通链接二维码打开小程序”的二维码规则，链接前缀使用上述地址。
3. 将打开页面设置为小程序的教室连接入口。客户端同时支持从启动参数 `q` 读取完整普通链接，因此也可以先进入默认页再自动跳转。
4. 发布包含该规则的小程序版本，并使用真机微信验证。开发工具的二维码规则与正式环境可能不同。

## 客户端配置

- 教室端：打开“教室连接二维码”，展开“允许直接使用微信扫码”，填写同一个 HTTPS 链接前缀并保存。
- 教师端：在扫码登录窗口展开同名设置，填写同一个链接前缀并保存。
- 清空链接并保存可随时回退到原有的小程序内扫码模式。

直达链接是公开路由配置，不是密钥。AppSecret 不应写入教师端、教室端、小程序源码或 Git 仓库。本实现不在客户端调用微信令牌接口，因此不会泄露 AppSecret。二维码只保存短期局域网配对信息或教室连接码；账户与教室数据仍通过局域网传输。
