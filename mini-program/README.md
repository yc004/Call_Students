# 教室呼叫微信小程序

配套教师移动端，复用教室端 `ws://教室IP:3456` 局域网协议。

## 当前功能

- 扫描教师端“账户管理”生成的二维码登录；
- 登录凭证、教室列表和当前教室持久保存在微信本地，后续自动登录；
- 前台自动连接，断线自动重连；
- 使用微信原生导航栏、`tabBar`、操作菜单和半屏组件，主页面切换时保留页面实例；
- 搜索并呼叫学生；
- 按日期和学科查看作业，按教师权限布置新作业；
- 实时查看当前在教室、今日已到、已离开及未识别学生，并查看摄像头捕获的人脸图片；
- 班主任可额外查看待匹配人脸，普通任课教师只能接收已识别学生的画面；
- 切换教室、手动添加局域网 IP、主动退出登录。

## 小程序图标

正式图标文件位于 `assets/icons/`。该目录在小程序源码根目录 `src/` 之外，只用于微信公众平台和品牌展示，不会进入上传包：

- `mini-program-icon-1024.png`：微信公众平台上传及主素材；
- `mini-program-icon-512.png`：通用高分辨率版本；
- `mini-program-icon-256.png`：文档与仓库预览；
- `mini-program-icon-source.png`：生成源图，供后续重新裁切。

图标以手机、呼叫气泡和学生群体为核心，与桌面端保持蓝白色视觉体系，橙色圆点表示即时通知。图标不包含文字，在 64px 缩略尺寸下仍可辨识。

## 开发运行

1. 使用微信开发者工具导入本目录；
2. 仓库中的 `project.config.json` 使用微信游客 AppID；首次导入后，在开发者工具中选择正式 AppID，工具会将它保存到已被 Git 忽略的 `project.private.config.json`，不要把正式 AppID 写回公共配置；
3. 开发阶段可使用游客模式或测试号；
4. 真机需与教室电脑在同一可互通局域网，并允许微信访问本地网络；
5. Windows 防火墙需允许教室端在专用网络监听 TCP 3456 端口。

可上传的小程序代码全部位于 `src/`，`project.config.json` 已通过 `miniprogramRoot` 指向该目录。不要将大尺寸品牌图、设计稿或文档放入 `src/`，否则可能触发微信主包 2MB 限制。

局域网 IP 连接属于小程序允许的本地网络场景，可使用 `ws://IP:3456`，无需配置公网 WebSocket 合法域名。若校园 Wi-Fi 启用了终端隔离或 VLAN 隔离，需由网络管理员放通。

## 登录与保持在线

二维码包含教师端已有登录密钥和最多 8 个已保存教室。扫码成功后凭证写入小程序本地存储；小程序每次启动或回到前台时自动恢复会话并连接当前教室。微信不允许小程序无限期在后台维持 WebSocket，因此这里的“一直在线”指无需再次登录，回到前台后自动恢复连接。

当前二维码是可离线工作的长期登录凭证，请只在本人手机上扫描，不要转发截图。后续若需要远程吊销手机登录，应升级为一次性配对码和设备令牌机制。
