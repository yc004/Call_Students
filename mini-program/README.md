# 教室呼叫微信小程序

配套教师移动端，使用教室端显示的 9 位连接码接入局域网教室。

## 当前功能

- 小程序教师账户作为身份源，通过扫描电脑教师端二维码完成电脑登录；
- 底部 Tab 栏中央提供统一“扫码”入口，可登录电脑教师端或扫描教室二维码添加教室；
- 已连接教室的班主任可通过微信原生分享卡片邀请其他教师，接收者点击后直接进入教室连接确认页；
- 底部始终只保留“首页、扫码、我的”三个一级入口；
- 呼叫、作业和出勤归属于具体教室，需从首页选择教室后进入对应二级页面；
- 点击底部扫码按钮会直接打开微信扫码器，并自动识别教室二维码或教师端登录二维码；
- 首页按天展示欢迎语，并汇总全部已保存教室的今日作业、截止阶段和提交人次；
- 也可直接在小程序中创建本地教师账户，扫码登录教师端时自动同步账户与教室列表；
- 配对取得的教师身份、教室列表和当前教室保存在微信本地，后续自动登录；
- 前台自动连接，断线自动重连；
- 使用微信原生导航栏、`tabBar`、操作菜单和半屏组件，主页面切换时保留页面实例；
- 搜索并呼叫学生；
- 按日期和学科查看作业，按教师权限布置新作业；
- 实时查看当前在教室、今日已到、已离开及未识别学生，并查看摄像头捕获的人脸图片；
- 班主任可额外查看待匹配人脸，普通任课教师只能接收已识别学生的画面；
- 扫码或手动输入连接码添加教室、切换教室、主动退出登录。

## 小程序图标

正式图标文件位于 `assets/icons/`。该目录在小程序源码根目录 `src/` 之外，只用于微信公众平台和品牌展示，不会进入上传包：

- `mini-program-icon-1024.png`：微信公众平台上传及主素材；
- `mini-program-icon-512.png`：通用高分辨率版本；
- `mini-program-icon-256.png`：文档与仓库预览；
- `mini-program-icon-source.png`：生成源图，供后续重新裁切。

图标以手机、呼叫气泡和学生群体为核心，与桌面端保持蓝白色视觉体系，橙色圆点表示即时通知。图标不包含文字，在 64px 缩略尺寸下仍可辨识。

## 开发运行

1. 使用微信开发者工具导入本目录；
2. 仓库中的 `project.config.json` 使用微信游客 AppID；首次导入后，在开发者工具中选择正式 AppID，工具会将它保存到已被 Git 忽略的 `project.private.config.json`，不要把正式 AppID 写回公共配置；
3. 开发阶段可使用游客模式或测试号；
4. 真机需与教室电脑在同一可互通局域网，并允许微信访问本地网络；
5. Windows 防火墙需允许教室端监听 TCP 3456，并允许教师端扫码配对使用 TCP 3457。

可上传的小程序代码全部位于 `src/`，`project.config.json` 已通过 `miniprogramRoot` 指向该目录。不要将大尺寸品牌图、设计稿或文档放入 `src/`，否则可能触发微信主包 2MB 限制。

连接码会在设备内临时还原为局域网地址并建立 WebSocket，不会在界面或登录二维码中暴露 IP。若校园 Wi-Fi 启用了终端隔离或 VLAN 隔离，仍需由网络管理员放通。

## 登录与保持在线

教师端登录二维码只包含教师端的局域网地址、临时 TCP 端口、随机配对码和过期时间，不包含教师账户或教室连接信息。小程序从底部中央“扫码”入口选择“登录电脑教师端”后，使用微信原生 `TCPSocket` 上传当前小程序教师身份和教室列表；教师端验证后完成登录，并以小程序数据完整替换本机旧账户和旧教室数据。成功传输后立即关闭服务并使二维码失效，未使用二维码也会在 2 分钟后失效。

教室二维码使用独立格式，只包含教室名称和经过校验的 9 位局域网连接码，不包含教师账户、学生名单或作业等班级资料。教室端首次引导页会直接显示二维码，完成配置后也可从系统托盘的“显示教室连接二维码”随时重新打开。

## 分享教室

班主任连接教室后，可在底部中央“扫码”页面点击“分享当前教室给教师”，通过微信原生分享面板发送卡片。卡片只携带教室名称和经过校验的连接码；接收教师点击卡片后进入专用确认页，以自己的教师账户添加教室。首次连接仍需班主任批准，不会通过分享继承班主任权限。若接收教师尚未登录，小程序会先引导其创建或登录账户，完成后自动返回该教室连接页。

配对成功后会话写入小程序本地存储；小程序每次启动或回到前台时自动恢复会话并连接当前教室。微信不允许小程序无限期在后台维持 WebSocket，因此这里的“一直在线”指无需再次登录，回到前台后自动恢复连接。配对时手机与电脑必须处于同一可互通局域网，且系统防火墙需要允许教师端接收入站连接。
